# Hindsight Cognitive Customer Support Agent

Enterprise Dual-Bank AI Support Engine built with Hindsight Cloud (hindsight-client v1.2.0), DeepSeek v3.2 via OpenRouter, and Streamlit.

## Quickstart
1. pip install -r requirements.txt
2. python seed_hindsight.py
3. python test_agent.py
4. streamlit run app.py
